{\footnotesize\ttfamily void Cgame\+Map\+::advance\+Round (\begin{DoxyParamCaption}\item[{const int}]{Roundnum }\end{DoxyParamCaption})}



Function responsible for advancing the round. 

Function for Roundnum rounds advances the game. Per each round the function first checks whether one the game ending conditions have been met After that it places all avaiable towers that can be placed and attacks with the towers. All of the killed attackers are removed. After this each attacker recalculates their path moves forward along it. If an attacker reaches the end it is removed from the game after dealing damage to the enemy\textquotesingle{}s HP and the player is awarded score and money. Finaly all of the towers that have been killed by the attacker are removed and additional money for the player is calculated from the HP diffrence
