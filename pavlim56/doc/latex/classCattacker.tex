Function for finding the shortest path to the exit using the A$\ast$ algorithm. 

Function uses the A$\ast$ algorithm to determine the shortest path to the exit. Each tile is visited and given a distance value of how long it takes to get from said tile to the end. The tile\textquotesingle{}s distance is artificialy inflated if it has a tower on it. The algorithm returns the path from exit to unit so the function reverses it and marks each tile as being a path tile.
