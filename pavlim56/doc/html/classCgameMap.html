◆ advanceRound()

void CgameMap::advanceRound ( const int  Roundnum)

Function responsible for advancing the round.

Function for Roundnum rounds advances the game. Per each round the function first checks whether one the game ending conditions have been met After that it places all avaiable towers that can be placed and attacks with the towers. All of the killed attackers are removed. After this each attacker recalculates their path moves forward along it. If an attacker reaches the end it is removed from the game after dealing damage to the enemy's HP and the player is awarded score and money. Finaly all of the towers that have been killed by the attacker are removed and additional money for the player is calculated from the HP diffrence

Parameters
RoundnumNumber of rounds the user wishes to advance

bool CgameMap::readMap ( list< string > &  map)

Function for reading ASCII and data of a map.

Function reads inputed data and checks whether it is correct or not. It checks the ASCII art of the map and checks for entrances, exits and invalid characters. After it finishes reading the data, function further checks calls check access, checks whether the sequence of entrances is correct and that there is only one exit. Finaly the function inputs pointers to all empty spaces into c_empty_spaces
