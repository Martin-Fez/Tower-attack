◆ findPath()

void Cattacker::findPath ( weak_ptr< CMapTiles >  end_tile)

Function for finding the shortest path to the exit using the A* algorithm.

Function uses the A* algorithm to determine the shortest path to the exit. Each tile is visited and given a distance value of how long it takes to get from said tile to the end. The tile's distance is artificialy inflated if it has a tower on it. The algorithm returns the path from exit to unit so the function reverses it and marks each tile as being a path tile.

Parameters
end_tileTile to reach

void Cattacker::move_foward ( list< shared_ptr< Cattacker >>::iterator  it)

Moves the attacker speed amount of tiles.

Attempts to move attacker up to the amount of tiles it's speed atribute allows it to. If must always end on a unoccupied tile. If it runs into a tower, it attacks it. If it runs into a another attacker and it is faster than it, it can pass this attacker.

ititerator to the unit's pointer within the container it is located in
